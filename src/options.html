Bye Tab

Tabs matching a pattern below get a countdown in the corner, then close on their own. Changes save automatically.

URL patterns

* matches any characters. The whole URL has to match. A pattern without :// matches any scheme.

  • example.com/*: every page on example.com
  • *://*.example.com/*: plus its subdomains
  • */logout*: any logout URL on any site

Test a URL

Type a URL to check it against the patterns above.
